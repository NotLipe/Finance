# Finance

Ferramenta de controle de gastos — inicialmente para uso pessoal, com planos de ser disponibilizada para outras pessoas no futuro.

## Estrutura

- [`alpha_0.1/`](alpha_0.1/) — primeiro esboço: web app com transações, categorias, resumo mensal, gráficos e importação de extrato CSV. Veja o README da pasta para rodar.
- [`alpha_0.2/`](alpha_0.2/) — versão atual: tudo da 0.1 + categorias de despesa "Cartão de crédito" e "Investimentos" (aportes mensais) e criação de categoria direto do formulário de transação.

O histórico de mudanças está no [CHANGELOG](CHANGELOG.md).
